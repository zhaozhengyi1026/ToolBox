MD ↓ PDF

md2pdf

把引用了本地图片的 Markdown，完整转换成适合阅读和打印的 HTML / PDF。

  • 自动嵌入本地图片，不怕换电脑丢图
  • 支持目录、章节编号和格式检查
  • 可批量转换整个文件夹
python md_to_html.py "." --toc --pdf
