# MyACG

MyACG 是一个可以免费阅读小说和漫画的手机软件，并支持自动搜索内容。

## 下载与安装

1. 下载当前目录中的 [`MyACG.apk`](MyACG.apk)。
2. 将安装包发送到 Android 手机并打开。
3. 如果系统提示禁止安装未知来源应用，请根据手机提示临时授予安装权限。
4. 安装完成后即可打开使用。

安装包 SHA-256：`EB0327E82E7E74179F8463568284E03EE8F33E91AB2BC2E87C4BCA1248697DA2`

## 主要功能

- 阅读小说
- 阅读漫画
- 自动搜索内容
- Android 手机直接安装

## 注意事项

- 安装前建议核对文件来源，并使用手机安全软件进行检查。
- 软件中的搜索结果和内容可能来自第三方服务，稳定性与可用性可能发生变化。
- 请支持正版内容，并遵守当地法律法规、版权要求及相关服务条款。
