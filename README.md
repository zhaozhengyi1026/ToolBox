# ToolBox

这里收集一些我个人觉得实用的小工具，并会持续更新。

## 工具列表

### md2pdf

将 Markdown 文档转换为便于阅读、打印的独立 HTML，也可以继续调用 Chrome 或 Edge 生成 PDF。

- 支持单个文件和文件夹批量转换
- 支持目录、章节编号和格式检查
- 支持嵌入本地图片
- 支持自动生成 PDF

详细说明请查看 [md2pdf 使用说明](md2pdf/md_to_html使用说明.md)。

### MyACG

一个可以免费阅读小说和漫画的手机软件，支持自动搜索内容。

安装包和使用说明位于 [阅读小软件](阅读小软件/README.md)。
