压缩方式说明

每一页会重新渲染为图片再生成 PDF，压缩效果更稳定，但文字搜索、超链接、表单和复制文字功能不会保留。原文件不会被修改。

将压缩全部页面，推荐先使用“均衡”。

正在读取 PDF请不要关闭页面

使用方法

同一份 PDF，三种处理方式。

拆

拆分 PDF

按单页快速生成列表，或勾选任意页面合成一份；下载前可直接修改文件名。

图

PDF 转图片

勾选特定页数，选择 PNG 或 JPG 和清晰度，然后下载图片或 ZIP。

压

压缩 PDF

用三个预设控制体积和清晰度，重新生成一份更适合传输的 PDF。

ToolBox

所有 PDF 处理均在本地浏览器中完成。
